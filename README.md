# Amazon Clone (SuperSimpleDev JavaScript Course)

A shopping website built while following the SuperSimpleDev JavaScript course. This is a course project: I completed all exercises from the basic to the advanced ones, and where possible I implemented them more thoroughly than the course required.

## Pages
- **Home:** product listing with add-to-cart
- **Checkout:** order summary and delivery options
- **Orders:** order history
- **Tracking:** order tracking

## Tech
- Vanilla JavaScript (ES modules), HTML, CSS
- Unit tests with Jasmine (`jasmine-standalone-7.0.1/`)
